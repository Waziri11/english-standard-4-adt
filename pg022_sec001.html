Activity 2.2:

Expressing quantity using ‘some’ and ‘any’

(a) Study the following sentences paying attention to the word ‘some’.

1. I need some money to buy a new book.

2. There is some sugar in the pot.

3. I ate some bread before I left for school.

(b) Study the following sentences paying attention on the word ‘any’.

1. I don’t have any money today.

2. There isn’t any sugar left.

3. I don’t know any person in Nduruma village.

(c) Read/sign the following dialogue and determine the rule that applies when using ‘some’ and ‘any’.

James: Hi, Jane.

Jane: Hi, James.

James: I’m going to the shop now. Do you need any milk?

Jane: No, I don’t need any milk, but I need some sweets and some apples.

James: Okay. How about biscuits?

Jane: There are some biscuits in the cupboard. I don’t think I need any more biscuits.

James: We don’t have any chocolates left last night. Do we?

Jane: Oh yeah, we don’t. I think you need to get some chocolates from the shop.
